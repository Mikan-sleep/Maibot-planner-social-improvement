运行参数

保存后立即生效；写入插件数据库，不改 config.toml
启用社交策略 ?启用社交策略总开关。关闭后不再向 Planner 注入社交状态，也不会执行强制改写；已经保存的消息和决策仍按保留期保留。
关掉后回到“原始 Planner”，适合排查问题。
回复阈值 ?回复阈值（0~1）策略分数达到它才建议回复。调低会更容易开口，调高更安静；建议 0.30~0.50。太接近 0 会让机器人在无关话题也接话。
默认 0.38；调低=更活跃。
发言频率倍率 ?发言频率倍率（0.2~3）直接乘到 Maibot 本会话的 talk_value。调高会让 Planner 更频繁地进入思考；1.0 表示不改变。调得过高会增加 token 消耗和插话概率。
默认 1.8；1.0=不改变原频率。
社交参与模式 ?社交参与模式conservative：只接点名/引用；balanced：相关才接；active：允许未被点名时短评。它改变提示里的发言倾向和硬规则，不直接改 talk_value。
默认 active；太吵时先切 balanced。
机器人容忍度 ?机器人容忍度（0~1）群友对机器人主动发言的容忍度通常高于人类。数值越高，策略越不把“没被点名”当负分；调高会更容易接话，调低更接近严格人类话轮规则。
默认 0.8；建议 0.6~0.9。
反馈判定方式 ?反馈判定方式llm：调用模型判断正/负/中性，最准但耗 token；hybrid：关键词即时 + 模型补模糊；keyword：只靠关键词，最省但容易误判反讽和玩笑。
默认 llm；失败/低置信度不会污染权重。
学习步长 ?学习步长（0.001~0.5）每次反馈更新策略权重的幅度。调大学习快，但容易被单次误判带偏；建议 0.01~0.10。改动只影响之后的新反馈。
默认 0.05；调小更稳。
允许强制改写 reply ?强制改写 replyPlanner 已经决定 stop/wait 时，插件把它改成 reply，这是对Maibot原始Planner决策的直接改写。默认关闭；开启前请保留下面的冷却和负反馈锁定。
默认关闭；打开后每轮 stop 都可能变成开口。
强制改写最低分 ?强制改写最低分（0~1）只有策略分数达到它才允许把 stop 改成 reply。调高更安全、开口更少；调低更容易强制回复。建议不低于 0.20。
默认 0.2；不要设 0。
强制改写冷却 ?强制改写冷却（秒）两次强制改写之间至少间隔多久。调大能明显降低连发/刷屏风险；被直接 @ 或引用机器人时可豁免。
默认 60 秒；不建议低于 30。
刚发言保护 ?刚发言保护（秒）机器人刚说过话的这段时间内不强制改写，避免自己接自己。被直接 @/引用机器人时不受此限制。
默认 90 秒；防连续追问。
负反馈锁定 ?负反馈锁定（秒）收到明确负反馈后，强制改写暂停多久。调大更保守；这是防止“被说别插嘴还继续插”的最后一道闸。
默认 900 秒（15 分钟）。
参数保存后立即应用
提示：强制改写默认关闭。开启前先确认冷却/刚发言/负反馈锁定三项保护，避免过于连续和频繁的插话。

频率闭环与强制保护

自动频率根据近期回复率微调；强制改写只允许白名单群
自动频率 ?自动频率开启后，每 N 条用户消息根据近 2 小时回复率自动微调倍率；手动倍率仍作为基准。默认关闭，避免突然变吵。
目标回复率 ?目标回复率（0~1）机器人消息 / 用户消息。0.08 约等于每 100 条用户消息回 8 条。设得太高会更容易插话；建议 0.05~0.12。
调整间隔 ?调整间隔（用户消息数）每多少条用户消息评估一次。太小会抖动、太大反应慢；建议 20~50。
调整步长 ?调整步长每次自动调整的倍率幅度。0.1 表示 1.0→1.1；太大容易过冲，建议 0.05~0.15。
自动倍率下限 ?自动倍率下限闭环最多把自动倍率降到多少；手动倍率会再乘上去。太低可能几乎不进入 Planner。
自动倍率上限 ?自动倍率上限闭环最多把自动倍率升到多少；调高会更积极，但也更容易刷屏。
强制改写白名单 ?强制改写白名单填群号，逗号分隔；只有列表里的群允许强制 reply。留空=不允许强制；填 * 才允许全部群（不建议）。
自动关闭阈值 ?自动关闭阈值同一群累计多少次负反馈后自动关闭强制改写。0 表示不自动关闭；这是防“被说别插嘴还继续插”的熔断。
自动频率和强制白名单都默认保守；先看 24 小时指标，再逐步放开。
